# Pranita R - Portfolio

Personal portfolio site showcasing my work across blockchain, backend, and AI engineering.

Live site: pranita18.netlify.app

## About

A single-page portfolio built to highlight experience spanning three domains — smart contract development, scalable backend systems, and AI/LLM integration — along with featured projects and a way to get in touch.

## Built with

- HTML, CSS, and vanilla JavaScript — no framework, no build step
- [Fraunces](https://fonts.google.com/specimen/Fraunces), [Inter](https://fonts.google.com/specimen/Inter), and [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) via Google Fonts
- [Netlify Forms](https://docs.netlify.com/manage/forms/setup/) for the contact form (no backend required)

## Features

- Responsive layout with a mobile hamburger menu
- Scroll-based active section highlighting in the nav
- Click-to-copy email and phone number
- Contact form that submits directly through Netlify — no email client required
- Sections: Home, About, Experience, Projects, Skills, Contact

## Running locally

No build step needed — just open `index.html` directly in a browser, or use a tool like VS Code's Live Server extension for auto-refresh while editing.

## Deployment

Deployed on [Netlify](https://www.netlify.com/), connected directly to this repository. Any push to the main branch triggers a new deploy automatically.
